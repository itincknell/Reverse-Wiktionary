## Failure Points

```text
first_attempt: requirements.txt was produced from local pip freeze and included
packages that were not installable on the VM Python version.

second_attempt: Azure Run Command was used as the long-running job supervisor
and timed out after the embedding run had already completed.

snapshot_step: Qdrant snapshot creation used the old 600 second timeout, which
was too short for the full product collection.
```

## Fixes Applied

```text
requirements.txt now contains direct runtime dependencies only.
remote execution now submits a background systemd unit and exits quickly.
remote status.json and remote_embedding_job.log are uploaded periodically.
the remote job creates a Python virtual environment before installing deps.
Qdrant snapshot timeout defaults to 3600 seconds in the VM job path.
snapshot-only rerun scripts can recover a completed collection without
regenerating embeddings.
```
